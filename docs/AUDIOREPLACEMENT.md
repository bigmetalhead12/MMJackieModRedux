# Audio Replacement
## Preface
I want to give a big thanks to [Magemods](https://github.com/magemods)'s [MM Audio API](https://github.com/magemods/mm-audio-api). Audio replacement in Majora's Mask: Recomp has been an aspect of MM modding that was so difficul that many talented and skilled modders started and gave up on this altogether. Magemod's contribution with this API is arguably one of the most noteworthy milestone of the MM modding community, and modding MM's audio would not have been this easy (let alone possible) without it.
